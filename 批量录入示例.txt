# ============================================
# FF14 材料台账 · 批量录入示例
# ============================================
# 用法：打开「＋ 批量粘贴录入」，先把下面的内容复制进去，
#      然后在左边选好角色和默认位置，点「开始导入」。
#
# 格式：材料名 数量 [位置] [hq]
#   · 名称必须是物品库里的标准名，或你加过的备注名
#   · 数量可以写 1523，也可以写 1组524
#   · 位置省略时，用左边选中的默认位置
#   · 末尾加 hq 表示高品质
#   · 以 # 开头的行是注释，会被跳过
#
# 重要：同名材料 + 同一角色 + 同一位置 + 同一品质 是【覆盖】不是累加。
#      写两行只保留最后一行；导错了到下方「快照」里恢复。
# ============================================

# —— 背包 ——
黑铁锭 1组524
黄铜锭 300 hq
亚麻 600

# —— 雇员仓库 ——
黑铁锭 640 雇员1
玄铁矿 120 雇员2

# —— 部队柜 / 房屋 ——
白钨矿 12 部队柜
黄铜锭 85 房屋

# —— 备注名也能用（铁锭 是黑铁锭的备注名）——
铁锭 500
