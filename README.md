# FF14 材料台账

记录 FF14 材料分散在各个角色、雇员、部队柜里的数量，之后按材料名、角色、位置一次搜全。附带配方算料、Universalis 市场查价和买入成本统计。

本地运行，数据只存在你自己电脑上的一个 SQLite 文件里。这是非官方工具，见文末[声明](#声明)。

## 能做什么

- **查库存**：材料名、角色、账号、服务器、位置一次匹配，按材料分组显示合计、组数和占用格数
- **记账**：存、取、改、搬位置，每一步都写流水；支持批量粘贴、CSV 导入导出
- **部队柜**：按共享仓库处理，多人重复记录同一材料时提示冲突
- **买入成本**：按批次记采购单价，自动算加权均价和估值
- **算料清单**：多个成品一起算，给出要买的材料、要做几批半成品、买齐要多少金
- **查价**：Universalis 国服四个大区的挂单价，能从 NPC 用金币买的另外标出
- **防丢数据**：每次写操作后自动快照，可查看、恢复、下载；还有撤销上一步、对账和审计

## 开始使用

### 方式一：下载打包好的程序（推荐）

1. 到 [Releases](../../releases) 下载最新的 zip，解压到任意目录（中文路径没问题）
2. 双击 `ff14-stock.exe`，浏览器会自动打开 `http://127.0.0.1:8765/`
3. 用的时候别关黑色的控制台窗口，关掉就是退出

不需要装 Python，物品表、配方表、NPC 商店价已经打包在里面。

### 方式二：从源码运行

需要 Python 3.9 或更新版本（安装时勾选 **Add python.exe to PATH**），不需要装第三方库。

双击 `启动.bat`，或者用命令行：

```
python app.py                 # 启动服务
python app.py --no-browser    # 启动服务但不自动开浏览器
python app.py --browser       # 强制用浏览器（装了内嵌窗口时）
python app.py --port 9000     # 换端口
python app.py --clear-demo    # 删除示例数据
```

### 首次启动会做什么

1. 新建 `data\` 目录和数据库 `data\stock.db`
2. 从源码运行且没有 `data\items.json` 时，从国服数据源下载物品表（约 19MB，只下一次）。下载失败不影响记账，只是输入材料名时没有联想
3. 灌入一组示例数据（账号名以「示例」开头）。正式使用前，点页面顶部横幅里的「清除示例数据」

## 界面

两栏工作台：**左栏查库存，右栏常驻「记一笔」**。审计、对账、成本、名字映射、快照、部队、数据急救、快捷键都收在右上角「管理」抽屉里。明暗主题跟随系统。

## 记账

### 位置与雇员

- **角色仓库**：背包、鞍囊、部队柜、房屋等
- **雇员**：雇员1、雇员2…，按数据里用到的最大序号自动生成；需要更多时点「＋ 新增雇员N」
- 选中某个雇员时右侧出现「删」，可清空这个位置。里面的库存不会消失，而是转入[未确认库存](#未确认库存)

### 录入、取出、修改

- **材料名必须能对上物品库或备注名**。输入时有联想下拉（↑↓ 选择，Enter 确认），对不上会拦住并弹出绑定窗口
- **数量**：一行三格「总数 / 组 / 余」联动，填 `1523` 或 `1组524` 都行，下方实时显示换算和占用格数。只存总数，组和格只是显示
- 每行右侧：
  - **取**：减库存，取到 0 自动删除这一行
  - **改**：把这一行填回表单，改完保存即覆盖；同时改位置就是搬货
  - **删**：点两次确认
- 数量和原来一样时只提示「未产生改动」，不写流水、不打快照
- 不可堆叠的物品（家具、装备）标「单体」，不接受「N组」。堆叠上限来自物品表，不是写死 999
- 超过 14 天没更新的行标黄

### 搬位置

搬货只改位置，**总数不变**：

| 方式 | 操作 | 适用 |
|---|---|---|
| 一次搬完 | 行内「改」→ 同时改数量和位置 → 保存 | 日常推荐，一步完成 |
| 分两步 | 旧位置「取」→ 新位置「记一笔」 | 想分开记录时 |
| 整格搬 | 位置旁「删」→ 转入未确认 → 再转移 | 整个雇员栏位没了 |

一次搬完会写「搬出」「搬入」两条流水，审计里这个材料的净变化是 0。

### 批量粘贴录入

「＋ 批量粘贴录入」，一行一条，格式 `材料名 数量 [位置] [hq]`，`#` 开头的行是注释：

```
黑铁锭 1组524
亚麻 300 雇员1
黄铜锭 60 hq
```

- 位置省略时用左边选中的默认位置
- **同一角色、位置、材料、品质是「覆盖」不是「累加」**：写两行只保留最后一行
- 一次最多 500 行，完成后逐行列出成功 / 未变 / 失败

仓库里的 `批量录入示例.txt` 是一份可以直接粘贴的样例。

### 部队柜

部队柜是**共享**仓库，多个角色各记一份会让合计翻倍。

- 建部队 → 角色加入 → 录库存时位置选「部队柜」
- 同一材料被多人记过时，面板提示**冲突**
- 「归并部队柜」：数量由你确认（不自动求和），旧行作废并写流水
- 解散部队：先自动打快照，再二选一
  - 按解散处理：库存作废并留流水（FF14 里部队解散后箱里的东西会消失，不能挂回角色）
  - 我已经把东西搬空了：直接解散

### 未确认库存

删掉一个雇员栏位时，里面的库存**不会被删除**，而是转入「未确认库存」。库存是实物，不能因为栏位没了就消失。

在「管理 → 未确认库存」里处理：

- **转移**：选角色和位置，并入目标格（目标格已有同材料则相加）
- **丢弃**：真正删除，先自动打快照，并写流水留痕

未确认的库存不计入主列表和合计，顶部单独显示，例如 `未确认 2 行 260 件`。

### 买入成本

录入时填「买入单价」才记成本，且**只有数量增加才记**（清点、覆盖、减少都不算采购）。

- 材料标题显示 `均 16.7 gil · 2 批 · 估值 110,123`，点开展开批次明细
- 均价按数量加权；删掉某个批次，均价立刻重算
- 没有批次的旧库存，点「设成本 ⊕」填一个基线单价

### 名字对不上怎么办

**备注名**：一个物品可以挂多个备注名。打 `铁锭` 会自动解析成 `黑铁锭`，搜 `铁锭` 也能找到 `黑铁锭` 的库存。记录里始终存标准名，备注名只用于输入和搜索。在「管理 → 名字映射」里增删。

**物品库没收录**：结果里显示「（未收录）」时，点那行的「绑定」，三选一：

- 搜中文名片段，从本地物品库挑
- 搜英文名（例如 `Iron Ingot`），去 XIVAPI 查
- 直接填物品 ID

游戏刚更新、数据还没收录的新物品，可以点「这批先按原名临时记录」，等数据更新后在「未收录的材料」里补绑。

## 算料清单

不记库存也能用：把要做的东西放进清单，程序算出要什么材料、自己要做几批、买齐要多少金。

1. 打开算料页面，输入成品名和数量，点「＋ 添加」继续加；也可以粘贴一批，一行一个 `名称 x 数量`
2. 点「生成总清单」。清单存在浏览器里，刷新不丢

**同名材料自动合并**：同一材料被多个成品需要时，需求先相加，库存只扣一次，批数只取整一次。比如两个成品各要 1 个「高地小麦粉」、每批产 3 个，结果是做 1 批，不是 2 批。

结果分三组：

| 分组 | 意思 |
|---|---|
| 待获取 | 还得去弄到的材料（含你指定「直接买」的半成品） |
| 待制作 | 需要自己做的半成品，写明做几批、多做几个 |
| 已备齐 | 库存已经够的部分 |

- **使用库存**：开着按仓库实际数量扣减；关着只算理论需求。库存为空时自动进入纯算料模式
- **HQ**：每个成品可以单独勾。勾了只抵扣仓库里的 HQ 材料；没有 HQ 版本的物品自动按 NQ 算

### 价格

- **市场价**：查 Universalis 当前挂单，缓存 5 分钟
- **买齐成本**：按挂单从低到高逐档吃，不是「最低价 × 数量」：

  ```
  需要 20 个：46 金 × 1 + 60 金 × 12 + 75 金 × 7 = 1,291 金
  （按最低价 × 20 只有 920，会低估）
  ```

- **NPC 金币价**：能从 NPC 商店用金币买的物品另给单价，比市场便宜时标出来
- **买还是自己做**：同一个半成品同时列出「直接买」和「按材料自己做」的价格，由你自己判断

价格都是估算，不含市场税，不保证能按这个价买齐。

## 防丢数据

### 快照

**每次存、取、改、删、改备注名成功后，自动给数据库存一份快照**。自动快照只保留最近 30 个，大约等于「最近 30 步可回滚」。

| 操作 | 说明 |
|---|---|
| 立即打快照 | 手动存一份，可填备注（如「建仓完成」）。**手动快照不会被自动清理** |
| 查看 | 只读打开，看那一刻的库存 |
| 恢复 | 点两次确认，会提示丢失之后多少条操作。恢复前先把当前状态存成「恢复前」快照，恢复本身也能反悔 |
| 下载 | 把这份快照另存为 `.db` 文件 |
| 删 | 点两次确认，只删这一份 |

自动快照的备注是操作摘要，例如 `取出 黑铁锭 999 → 阿辉@豆豆柴 / 背包（剩 524）`。快照文件在 `data\snapshots\`。

### 撤销上一步

「最近操作」工具栏的「撤销上一步」（点两次确认）只撤销**最近一条**库存操作。原流水标为「已被撤销」，同时写一条撤销流水，账目仍可追溯。撤销本身不能再撤销，要回退更早的状态请用快照。

### 对账与审计

- **对账**：逐格比较「当前数量」和「这一格所有流水加起来」，有差异就列出来
- **审计**：按材料汇总一段时间（今天 / 7 天 / 30 天 / 全部 / 自选日期）内的新增、取出、覆盖、删除和净变化
  - 流水可以逐条勾「已核对」，或标成「异常」并写原因；异常的流水不计入统计
  - 同一物品 ID 的不同叫法合并成一行
  - 可复制汇总文本，或导出 CSV

### 数据急救

「管理 → 数据急救」显示真实数据库路径、大小、角色和库存数。

- **立即备份**：手动打快照
- **选择 .db → 导入并覆盖**：整份换回。替换前先校验表结构，原库自动备份为 `stock.bak-时间戳.db`，失败自动回滚
- **程序起不来时**：把 `.db` 文件拖到 `恢复数据.bat` 上

## 导入导出 CSV

**导出**：搜索结果右上角「导出库存 CSV」。带 BOM，Excel 直接打开不乱码。

**导入**：「＋ 导入库存 CSV」选文件后**先预览、不写库**，显示新增、覆盖、跳过各多少条，再选：

| 按钮 | 行为 |
|---|---|
| 覆盖导入 | 同一格（角色 + 位置 + 材料 + HQ）已有数据时，用 CSV 的数量替换 |
| 追加导入 | 已有数量加上 CSV 的数量 |
| 取消 | 什么都不写 |

- CSV 要带表头 `material,character,location,hq,qty`，`world`、`account` 可选
- 库里没有的角色会自动创建；同名角色有歧义时整批拒绝
- 物品名认不出的行跳过，结果里逐条列出
- 导入前自动打一份快照

**跨大版本升级前**（如 0.7.x → 0.10.x）：把 `data\stock.db` 拖到 `紧急拆封CSV.bat` 上，生成的 `01-库存（可直接导入）.csv` 可以在新版本里原样导回。

## 其他

- **快捷键**：「管理 → 快捷键」点「录制」后直接按组合键（必须带 Ctrl 或 Alt）。默认 `Ctrl+Enter` 保存、`Ctrl+K` 聚焦搜索。设置存在浏览器里，换浏览器不跟随
- **物品图标**：国服物品表没有图标字段，页面出现某个材料时才向 XIVAPI 批量取图标，结果缓存在 `data\icon_map.json`。取不到就留空。材料名旁的小号 `#5057` 是物品 ID，点一下可复制，方便手动查图
- **内嵌窗口**（从源码运行时可选）：双击 `安装内嵌窗口.bat`（装 `pywebview`），之后 `启动.bat` 会开一个没有地址栏的独立窗口。需要 Windows 的 WebView2 运行时（Win11 自带），缺失时自动回退浏览器

## 数据在哪

| 内容 | 从源码运行 | 打包版 |
|---|---|---|
| 数据库 `stock.db` | `data\stock.db` | exe 旁边的 `data\`；目录不可写时改用 `%LOCALAPPDATA%\ff14-stock` |
| 快照、日志、图标缓存 | `data\` 下 | 同上 |

- 想把数据放到别处（网盘、移动硬盘），设环境变量 `FF14_STOCK_DATA` 指向那个目录
- **备份就是复制 `data\stock.db`**，或者复制整个 `data\`
- 升级新版本时，把旧版的 `data\` 文件夹整个搬到新版旁边即可

物品、配方、NPC 价这三份游戏数据只是缓存，删了也能重新生成：

| 文件 | 用途 | 重建命令 |
|---|---|---|
| `data\items.json` | 物品表（名称、堆叠、能否 HQ） | `python app.py --build-items` |
| `data\recipe.json` | 配方索引 | `python app.py --build-recipes` |
| `data\npc_shop.json` | NPC 金币商店价 | `python app.py --build-npc` |

升级后发现「配方用不了」「NPC 价没有」，多半是这三个文件没更新。

## 遇到问题

| 现象 | 处理 |
|---|---|
| 双击后窗口一闪而过 | 双击 `诊断启动.bat`，报错会写进同目录的 `run.log` |
| 提示 Python not found | 从源码运行需要 Python 3.9+，安装时勾选 Add to PATH；或者改用打包版 |
| 页面打不开 | 看控制台窗口里打印的端口号。8765 被占用时会自动换成后面的端口 |
| 物品名没有联想 | 物品表下载失败。联网后运行 `python app.py --build-items` |
| 其他报错 | 看 `data\error.log`（带时间、接口名和堆栈），反馈时附上 |

浏览器打开 `http://127.0.0.1:8765/api/diag` 能看到物品表加载了多少条、名称能否正常解析、图标缓存了多少。

## 开发

目前只有 [Suethekitten](https://github.com/Suethekitten) 一人维护，暂不接受代码合并请求。问题和建议欢迎提 Issue。

- **跑测试**：测试会写数据，先把数据目录指到一个临时文件夹：

  ```powershell
  $env:FF14_STOCK_DATA="$env:TEMP\ff14-test"
  python -m unittest tools.tests.test_core
  python app.py --selftest
  ```

- **打包 exe**：先从源码运行一次，确保 `data\` 里有三份游戏数据，然后双击 `build_exe.bat`（首次会自动装 `pyinstaller`）。产物在 `dist\ff14-stock\`，要发的是整个文件夹，不是单独的 exe
- **生成发布 zip**：双击 `发布打包.bat`。zip 里不含你自己的 `data\`
- **版本记录**：见 [CHANGELOG.md](CHANGELOG.md)
- **前后端接口**：见 [docs/API.md](docs/API.md)；给 AI agent 的协作规则见 [AGENTS.md](AGENTS.md)
